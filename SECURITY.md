# Security reporting

Do not publish exploitable vulnerability details in a public issue. Use the private security-reporting channel provided by the repository host for the copy of PhishGuard you obtained, or contact the maintainer distributing that copy.

This source package does not configure a central security inbox. Community threat reporting is separate from vulnerability reporting and is disabled until the user configures an HTTPS relay and explicitly enables it.

When testing the extension, use a dedicated browser profile and a development build. Do not bypass an organisation’s extension-installation policy.
